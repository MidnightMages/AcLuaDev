# Advanced Computers Test Harness
This project intends to emulate an [Advanced Computers](https://github.com/MidnightMages/AdvancedComputers) execution environment, with some added features to accelerate development.

## Features
As the mod itself, this project uses our [JLuaVm](https://github.com/MidnightMages/JLuaVM) runtime which runs Lua 5.4 code and allows for saving the execution state, though the test harness is not aimed towards that and thus, unlike the Minecraft mod, does _not_ implement persistence.

The main focus is towards quickly being able to develop new operating systems or programs. By using this test harness, there is no need to boot up an entire Minecraft client/server as this is fully self-contained. It is also not needed to set up any kind of items as the source is simply loaded from a folder.

The code executes as quickly as possible, there is no arbitrary limiting of speed put in place.

Additionally, as soon as any file is modified on disk, the `shutdown` event is emitted, causing operating systems that listen for this event, to immediately shut down to then be restarted as quickly as possible. 

Thirdly, changes on disk are kept purely in memory and are discarded upon shutdown/restarting, though actually writing to disk can be enabled in the config.json file.

There are a few more settings in the config file which will be autogenerated when starting the program for the first time.

## Contributing

But feel free to develop your own software/operating system.
